# 甲板交火 · Deckfire

轻量原创网页 FPS，当前版本 **v0.3 公开测试**。游戏提供游客进入的运输船 AI 团队竞技；当前没有真人联机和收费服务。

在线试玩：https://yimanfan937-stack.github.io/yangzhaodashuaige/

## 已实现

- 5 对 5 单人 AI 团队竞技，20 / 40 / 60 次击杀目标，6 分钟上限，三档难度。
- AK47、M4A1、AWM；WebGL 第一人称 3D 枪械、瞄准、换弹、跳跃、爆头和击杀反馈。
- 实时战绩表、小地图、程序合成音效、结算命中率和爆头统计。
- 游客昵称、生涯数据、最近五场、等级经验，以及通过比赛积分解锁的纯外观涂装。
- 音量、瞄准灵敏度、视野、画质和准星设置；手机触控和暂停。
- 无 WebGL 时的 Canvas 兼容路径。兼容路径目前使用平面枪械，涂装暂不显示。
- 离线缓存和支持浏览器中的安装入口；首次联网且 Service Worker 安装成功后才能离线体验。

## 进度和收费边界

进度通过 `localStorage` 保存在当前浏览器；无账号、云同步或跨设备存档。清除网站数据会清除存档。代码对存储损坏和写入失败做了降级处理。

游戏积分通过完整比赛结算获得，没有充值、抽奖、真实货币或提现。重复结算由本次运行状态防重；积分与战绩由客户端计算，可被用户自行修改，**不能作为真实收费、正式排名或付费权益的可信凭据**。

当前成果属于可公开测试的商业原型，不是可直接收费运营的成品。后续需要确定发行对象与商业模式，并完成：

没有接入广告平台、支付商户或真实玩家数据收集服务。不要把“已发布网页”理解为“商业盈利已经验证”。

## 文件与维护

这是静态站点，无第三方运行时依赖，根目录直接作为 GitHub Pages 发布内容。

- `index.html`、`style.css`：大厅与战斗界面。
- `app.js`：设置、存档、成长、声音、战绩与安装入口。
- `game.js`：WebGL 主路径；`fallback.js`：Canvas 兼容路径。
- `visuals.js`：程序化模型与场景几何；`weapon.js`：兼容路径武器绘制。
- `combat-fx.js`：击杀反馈。
- `sw.js`、`manifest.webmanifest`：离线资源与安装描述。

发布修改时应同时更新 HTML / 脚本中的资源版本参数以及 `sw.js` 中的 `CACHE` 和 `VERSION`，避免新旧资源混用。Service Worker 不会强制中断正在进行的比赛。
